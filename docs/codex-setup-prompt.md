# 让 Codex 完成本机配置

在 **Windows 本地 Codex 会话**中打开本仓库，再复制下面的 prompt。学校登录需要你在打开的 Edge 中操作；其余安装、配置和验证可交给 Codex。

## 首次部署 prompt

```text
请在这台 Windows 电脑上配置当前仓库 USTC Report Watcher，让我可以直接查看中科大学术报告，并在登录 Windows 后及每 6 小时自动检查。

请阅读 README.md、docs/usage.md 与 config.example.yaml，然后直接执行安装和验证，不要只给命令让我自行操作。

默认配置：Asia/Shanghai；每 6 小时检查；通知关注全部确定线上/混合报告；疑似线上默认不通知；首次成功同步仅建立基线，最多一条汇总。保留现有 config.yaml、登录态和历史，不覆盖我的订阅。若此机器已有配置，先核对并补齐缺失项。

依次完成：
1. 检查 Python 3.11+、Microsoft Edge 与项目路径。在项目的 .venv 中安装项目依赖，执行 init；不要安装系统服务、开放端口或默认请求管理员权限。
2. 先运行离线测试确认程序可用，再启动 login 的可见 Edge 和保存登录窗口。让我自行输入学校账号密码、完成验证码/多因素认证，进入学术报告列表、翻一次页并打开一条详情，然后点击保存。不要替我处理认证，也不要让我在聊天中发送 Cookie、CAS Ticket 或 Authorization。
3. 我完成登录保存后，确认本机加密会话和实际数据源配置已生成。必要时执行 discover；不编造接口或把离线样例当成真实结果。
4. 执行一次真实 run-once，等待整批完成。检查分页数量、上次成功同步的完成时间及错误状态。失败时保留已有数据，定位错误；会话失效才请我重新登录。
5. 打开 show，确认“当前可选”和“线上会议”两个独立列表可查看；“当前可选”包括线下报告。没有线上报告时如实说明结果，不能为了展示而伪造数据。
6. 执行 test-notification，让我确认原生通知能点击打开本地列表。API 提交成功只表示已提交，不能宣称我已经看见。
7. 安装 install-task，核实当前用户交互式登录触发、6 小时重复触发、错过计划后补运行、pythonw 静默启动。重复安装应幂等。执行 status 并记录任务状态。
8. 检查 .auth/、data/、logs/ 和 config.yaml 不被提交；会话使用当前 Windows 用户 DPAPI 加密，不保存学校密码。保留现有运行目录，告诉我移动目录后要重新安装任务。

最后给出实际成功/失败的检查结果、如何双击启动、重新登录和卸载自启动，以及尚未实测的重启/睡眠/锁屏行为。只有必须由我完成的登录或人工确认才暂停；可独立完成的安装与检查继续执行。未经实测的行为不要标记为通过。
```

## 已有配置的排障 prompt

```text
请检查本机已有的 USTC Report Watcher，保留现有登录态、SQLite 历史和订阅配置，修复实际发现的问题。

先读取 README.md 与 docs/usage.md，执行 status 并查看脱敏日志。检查“立即刷新”是否启动真实检查、刷新中提示是否持续、整批成功后完成时间是否更新，以及后台任务完成后窗口是否自动更新。

核实任务 USTCReportWatcher 已启用、使用当前用户交互式会话、包含登录和每 6 小时重复触发；项目移动后更新实际路径。缺少依赖或任务时直接补齐。只有登录态过期时才打开 login 让我自行完成认证，不要让我发送 Cookie 或账号密码。

修复后执行相关测试和必要的真实检查，给出实际结果。失败不能清空历史，也不能把旧数据说成最新同步成功。不要无故卸载任务、删除数据库或重置订阅。
```

## 使用前提

Codex 需要访问这台 Windows 的项目目录、终端和网络。纯 Linux/云端会话无法验证本机任务计划程序、DPAPI 和桌面通知。提示词中的安装、自启动注册和测试属于用户明确要求的操作；学校认证由本人完成。

提示词围绕本项目的目标、约束和验收结果编写；关于 Codex 仓库上下文与提示词的一般说明，可见 [OpenAI 官方 Codex Prompting Guide](https://developers.openai.com/cookbook/examples/gpt-5/codex_prompting_guide)。本项目本身不调用 OpenAI API，不需要为报告抓取配置 OpenAI API Key。
