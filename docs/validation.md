# 验收记录 · 2026-10-14

## 已实测

* Python 3.11.11、本机 Microsoft Edge、Playwright 1.64.0。
* 正常交互登录后保存当前用户 DPAPI 会话；加密文件可复用，未保存账号密码。
* 真实列表 23 页、2,260 条，总数校验一致；39 条未来/未知时间详情校验报告 ID。
* 初次基线最多一条汇总；再次完整同步 `baseline=false`、`notification=none`。
* 当前可选 14 场，待参加线上/混合 0 场；已识别历史线上/混合 137 场。
* 原生 Toast `submitted`；协议点击入口已启动本地窗口。开始菜单快捷方式使用 IPropertyStore 设置 AppUserModelID；协议无需原检查进程存活。
* 当前用户任务可运行且实测退出码为 0；两个触发器、Interactive、默认 6 小时、隐藏 pythonw、跨进程锁。重复安装不产生额外任务；卸载、查询不存在和重新安装均成功。
* 50 项 pytest 自动测试通过；包含真实 Tk 窗口构建、两个页签切换，以及实际进程在中文/空格配置路径下执行干跑。
* 同步时间改为整批完成时间；新增运行开始/完成字段，旧数据库自动迁移且保留历史。验证了刷新中切换页签不会隐藏进度、完成后时间更新、其他进程同步后当前窗口自动更新。
* 离线 baseline → updated → 相同 updated 可运行；独立 demo 数据库保留 3 条，事件不随重复扫描增加。
* 源码、说明、导出的脱敏结构与日志按本机实际 Cookie 值扫描通过；未输出凭据。`.auth/`、`data/`、`logs/` 限制继承的访问权限，当前用户和 SYSTEM 保留访问。

## 已知边界与待环境验收

* 实际 Tk 页签集成测试验证内容分离；视觉布局在使用者本机窗口核验。
* 默认不查询已知过去报告的详情；历史线上数量可能漏掉只在过去详情中提及的线上方式。未来/未知时间/关注报告会补查详情。
* 没有确认学校独立报告深链，原始报告按钮回退官方入口；本地详情保留真实 ID 和内容。
* 尚未重启/注销 Windows；实际登录触发、睡眠恢复、锁屏/勿扰、自然会话过期与 Windows 10 仍需对应环境测试。
* 通知 `submitted` 不能证明每次均被人看见；未实现已读收据。
* DOM 回退代码可通过真实选择器配置使用，但学校页面 DOM 路径未实测；实际接入使用已确认 API。

需要补测时执行 README 中的 `test-notification`、`status`、`login`，不要发送 Cookie 或认证头。
